# GRC Project

This is a Vite + React + TypeScript frontend.

## Package Manager

This project uses npm. Keep `package-lock.json` as the single dependency lockfile.

Bun lockfiles such as `bun.lock` and `bun.lockb` should not be reintroduced unless the project intentionally switches package managers.

## Commands

```sh
npm install
npm run dev
npm run build
npm run test
npm run lint
```
